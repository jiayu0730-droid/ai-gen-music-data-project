src_final/

This folder contains the final production pipeline for the AI Music Market Analysis project.

Pipeline:

1. 01_collect_data.py
    Collect YouTube, iTunes and platform evidence.

2. 02_analyze_and_score.py
    Build market opportunity scores and analytical datasets.

3. 03_generate_reports.py
    Generate figures and markdown reports.

4. run_pipeline.py
    Execute the entire pipeline automatically.

Run:

python src_final/run_pipeline.py
